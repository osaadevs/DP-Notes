How this lecturer builds a question every quiz follows this order

PART 1 · 2–4 MARKSWhy this pattern?Name it and give reasons that fit the scenario.
PART 2 · 4–8 MARKSDraw itA state diagram, a class diagram, or both.
PART 3 · 3–6 MARKSWrite the JavaThe interface, the abstract class or the context class.
PART 4 · 3–5 MARKSThe twistA second pattern joins at the end. Parking → Adapter, scanner → Facade, course → Decorator, support desk → Template.
The big lesson from 2024 and 2025: the question usually gives you the class and method names ("Define a Coffee interface with getCost()…", "Write a BookFactory that returns FictionBook…"). Use their names exactly. The code in this note is written so you only have to swap names.
