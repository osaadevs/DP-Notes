What these papers are built on

  • All four questions are case-based, and a single case asks about two or more patterns, spread across the whole question rather than saved for the last part (exam briefing).
  • The shape of the past papers: identify the patterns with reasons → diagram → short Java → a follow-up part (challenges, HA/DR, SOLID, how two patterns connect).
  • Question 2 is microservices in every paper, because 2023, 2024 and 2025 all had it.
  • Scenarios the past papers haven't used yet: food delivery, smart home, online exams, ride-hailing, insurance, banking, EV charging, airline, hotel, returns.

How to practise do it like the real thing

  1. Time it. 2½ hours for 4 questions. Give each question about 35 minutes and move on when the time is up, even mid-answer. The lecturer's biggest warning: students write long first answers and run out of time for the last ones.
  2. Use only what you'll take in: the printed exam note and the past-papers booklet. The point is to check whether you can find things fast. Mark any page you had to hunt for.
  3. Start from the case, not the theory. First sentence: what the case needs ("The kiosk behaves differently in each state, so…"). Then name the pattern and give reasons tied to the case. Don't write everything you know about the pattern.
  4. Write something for every part. A name plus one reason earns more than a blank.
  5. Mark yourself with the answers booklet. Note what you missed, not just whether the pattern name was right.

How to mark yourself

  1. Pattern named correctly with its group: about a third of the marks for an "identify" part.
  2. Reasons tied to the case (not general theory): most of the rest. "Each state is a class, so pay() is refused in Idle" scores; "State is a behavioural pattern from GoF" alone does not.
  3. Diagrams: correct arrows, stereotypes and +/−/# matter more than neatness.
  4. Code: the exact interface and method names from the question, and it must compile in spirit.
  5. Where another pattern is reasonable, the answer says so. If you chose it and justified it from the case, give yourself the marks.
